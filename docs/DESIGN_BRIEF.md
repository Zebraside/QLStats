# QLStats — бриф для Claude Design

## Как использовать

1. Откройте Claude Design и создайте проект-прототип.
2. Привяжите папку `docs/` этого репозитория. В ней лежат `REQUIREMENTS.md` и `ARCHITECTURE.md` с полными правилами и форматом API. Весь репозиторий привязывать не нужно.
3. Вставьте целиком текст из раздела «Промпт» ниже, от первой до последней строки блока.
4. Выберите один из предложенных вариантов layout, доработайте его, проверьте по списку в конце файла.
5. Выполните Export → Claude Code handoff. Полученный промпт с URL бандла вставьте в Claude Code в этом репозитории для переноса в `index.html` / `app.js` / `style.css`.

## Промпт

```text
Задача: одностраничный публичный сайт статистики игрового сервера Quake Live. Аудитория — небольшое сообщество игроков (десятки человек): посмотреть, кто сейчас играет, кто сегодня лидирует, и сравнить себя с другими. Авторизации нет. Интерфейс полностью на русском языке. Приоритет — десктоп (от 1280 px), но мобильная версия (от 360 px) должна быть пригодной: карточки встают в колонку, таблица прокручивается горизонтально с закреплённой колонкой ника.

Правила и формат API — в привязанной папке docs/ (REQUIREMENTS.md, ARCHITECTURE.md). Новых метрик не придумывай.

Структура страницы, сверху вниз:
1. Шапка: название «QLStats», имя сервера, UpdateIndicator — ненавязчивая подпись «обновлено N с назад» (статистика обновляется раз в 30 с, без перерисовки страницы).
2. Блок «Текущий матч», компонент LiveMatch — самый динамичный, поэтому наверху. Индикатор «live», обновление раз в 5 с. Показывает карту, режим, время с начала матча (тикает), лимиты (например, «фраги 50 · 15 мин»). Ниже мини-таблица участников: ник, метка «бот», команда (цветная метка red/blue только в командных режимах), текущий счёт; лидер выделен акцентом. Под таблицей — «зрители: N». Счёт помечен как текущий: он приближённый, итоговый появится в статистике. Четыре состояния с текстами:
   - «Идёт матч» — полный вид;
   - «Разминка» — список игроков без счёта, текст «Разминка — ждём начала матча», карта неизвестна;
   - «Сервер пуст» — «Сейчас на сервере тренируется Птица!»;
   - «Нет связи с сервером» — приглушённый блок, «Нет связи с игровым сервером», визуально отличается от пустого сервера.
3. Блок «Статистика дня». Три карточки StatCard:
   - «Матчей сегодня» — число;
   - «Больше всего побед» — значение и LeaderList;
   - «Больше всего убийств» — значение и LeaderList.

   При равенстве LeaderList показывает всех лидеров; если их больше трёх, лишние сворачиваются в «+N». Под заголовком блока мелкая подпись: «день по московскому времени, сброс в 00:00».
4. Блок «За всё время» — те же три StatCard за весь период.
5. Таблица PlayersTable, 9 колонок: Ник, Матчи, Убийства, Смерти, Лучший стрик, Победы, Средняя точность (%), Самоубийства, Смерти от окружения.
   - Сортировка кликом по заголовку, повторный клик меняет направление. Активная колонка и направление показаны индикатором (стрелка).
   - При наведении строка подсвечивается.
   - Числа выровнены по правому краю, табличные цифры.
   - Точность выводится как «31,8 %», при отсутствии данных — «—».
   - Удобно читается на 30–50 строках: плотная, но не тесная, с липким заголовком.

Состояния (нарисуй каждое):
- EmptyState: сегодня матчей не было — карточки дня показывают «0» и текст «Сегодня матчей ещё не было».
- Загрузка: первая загрузка, скелетоны карточек и строк таблицы.
- Ошибка API: показываются последние полученные данные; UpdateIndicator меняется на «не удалось обновить, повтор через 30 с»; без данных — понятное сообщение.
- Много данных: таблица на 60 строк, LiveMatch на 12 участников (в том числе командный режим red/blue).
- Длинные ники: цветовые коды QL (^1, ^7 и т.п.) уже вырезаны на сервере, но ник может быть длиной до 30–40 символов. Он обрезается многоточием с полным текстом в title и не ломает карточки и таблицу.

Эстетика — задаю явно:
- Тёмная тема по умолчанию. Глубокий графитовый фон, не чистый чёрный.
- Настроение Quake: индустриальное, строгое, металл и бетон. Без китча, без огня и черепов, без копирования логотипов и шрифтов id Software, без стоковых иллюстраций и фотографий.
- Один акцентный цвет (например, тёплый оранжево-красный или кислотно-жёлтый — предложи), используется только для лидеров, активной сортировки и индикатора. Остальное — оттенки серого.
- Шрифты: для цифр моноширинный или геометрический с табличными цифрами (например, JetBrains Mono или Rajdhani); для текста — нейтральный гротеск с кириллицей. Только Google Fonts.
- Крупные цифры в карточках — главный визуальный акцент страницы.

Как работаем:
1. Сначала предложи 2–3 варианта layout низкой детализации (wireframe), различающихся компоновкой блоков. Например: всё в одну колонку или сводка с LiveMatch сбоку от таблицы.
2. После моего выбора проработай один вариант полностью, со всеми состояниями.
3. Называй компоненты единообразно и в коде, и в чате: LiveMatch, StatCard, LeaderList, PlayersTable, UpdateIndicator, EmptyState.

Технические ограничения для передачи в код. Результат будет перенесён вручную в статические HTML/CSS/vanilla JS без сборки и без фреймворков, страницу отдаёт Rust-сервер (axum). Поэтому:
- семантичный HTML: header, main, section, table/thead/th с aria-sort;
- все цвета, отступы, радиусы и размеры шрифтов — CSS-переменные в :root;
- без Tailwind, React и других библиотек, без иконочных шрифтов (иконки — inline SVG);
- данные подставляются из JSON ниже.

Проверь доступность: контраст текста не ниже WCAG AA (4.5:1, включая серый вторичный текст и акцент на тёмном фоне), видимый фокус, сортировка с клавиатуры, читаемость при масштабе 200 %.
```

## Что проверить в полученном дизайне

1. Есть все четыре блока (LiveMatch наверху), в каждом блоке сводки по 3 карточки, в таблице ровно 9 колонок с названиями из брифа. Лишних метрик нет.
2. Нарисованы все состояния: пустой день, загрузка, ошибка API (со старыми данными и без них), 60 строк, длинный ник.
3. Ничья лидеров отображается списком всех игроков и не ломает карточку. На мобильной ширине (360 px) карточки и таблица остаются пригодными.
4. Сортировка показывает активную колонку и направление; заголовки — `<th>` с `aria-sort`, работают с клавиатуры.
5. Цвета и отступы вынесены в CSS-переменные. Нет Tailwind, React и внешних библиотек, кроме Google Fonts.
6. Акцентный цвет один; контраст вторичного текста и акцента на фоне не ниже AA. Нет логотипов id Software и стоковых картинок.
7. LiveMatch читается при 8–12 участниках (в том числе red/blue): лидер виден сразу, метка «бот» не теряется, блок не выталкивает статистику за пределы первого экрана на десктопе.
8. Состояние «Нет связи с игровым сервером» явно отличается от «Сервер пуст», а ошибка обновления сайта — от обоих.
9. Подписи на русском: «обновлено N с назад», «день по московскому времени, сброс в 00:00». Точность в формате «31,8 %», «—» для пустой.
