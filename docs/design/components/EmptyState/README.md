Сообщение на месте отсутствующих данных: пустой день или ошибка API без данных.

**Что передать.** `QLStats.EmptyState({ kind, retryAt, onRetry })`.
- `kind: 'day'` — «Сегодня матчей ещё не было» и пояснение, что идёт в статистику. Ставится под рядом карточек дня, которые показывают «0».
- `kind: 'error'` — «Статистика пока недоступна», «Сервер статистики не ответил. Повторим автоматически через 30 с» с отсчётом до `retryAt` и кнопка «Повторить сейчас» (`onRetry`). Только когда данных ещё нет совсем; если данные есть — оставить их и сменить UpdateIndicator.

**Правила**
- Пустой день — пунктирная рамка без фона: это нормальное состояние, не авария. Ошибка — сплошная рамка на `surface-sunken`, иконка `ink`, `role="alert"`.
- Не путать с «Нет связи с игровым сервером» в LiveMatch — это другое состояние и другой блок.
