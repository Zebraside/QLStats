Блок «Текущий матч»: что происходит на сервере прямо сейчас, обновляется раз в 5 с и стоит первым на странице.

**Что передать.** `QLStats.LiveMatch(live, { receivedAt })`, где `live` — ответ `GET /api/live` как есть, `receivedAt` — `Date.now()` в момент получения ответа (от него тикает время матча). Для первой загрузки — `QLStats.LiveMatch(null, { loading: true })`. Возвращает `<section class="qs-live">`, который заменяет предыдущий. Таймер оживляет `QLStats.startTicker(root)`, запущенный один раз на странице.

**Состояния** (`data-state` на секции):
- `in_progress` — карта, режим, «идёт 07:42», лимиты («фраги 50 · 15 мин»; нулевые не показываются), ростер со счётом. Лидер (наибольший счёт больше нуля, при ничьей — все) подсвечен `accent-soft`, его место и счёт — `accent`. Под ростером «зрители: N» и сноска «≈ Счёт текущий и приближённый — итоговый появится в статистике после матча».
- `in_progress`, `team_mode: true` — ростер делится на «красные» и «синие», у каждой строки цветной чип команды, вместо счёта колонка «убийства» (поле `kills`).
- `warmup` — «Разминка — ждём начала матча», «карта: неизвестна», список без счёта.
- `empty` — «На сервере никого нет. Заходи!».
- `offline` — приглушённая плита со штриховкой: «Нет связи с игровым сервером», время обрыва по Москве из `offline_since`.

**Правила**
- Больше 6 участников в FFA — две колонки (1–6, 7–12), в командном режиме — колонка на команду. Уже 34rem колонки встают одна под другую.
- Метка «бот» — текстом, всегда видна, даже у обрезанного ника.
- Зрители (`team: "spectator"`) в ростер не попадают, только в счётчик.
- Не показывать командный счёт: до конца матча его нет.
- Индикатор live — единственное, что пульсирует на странице.
