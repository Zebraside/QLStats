Карточка сводки: одно крупное число, подпись-шильдик и при необходимости список лидеров.

**Что передать.** `QLStats.StatCard({ label, value, unit, leaders, emptyText, loading })`.
- `label` — «Матчей сегодня», «Больше всего побед», «Больше всего убийств» (в блоке «За всё время» — «Матчей всего» и те же два).
- `value` — число из `/api/summary` (`matches` или `top_*.value`).
- `unit` — три формы для склонения: `['матч','матча','матчей']`, `['победа','победы','побед']`, `['убийство','убийства','убийств']`.
- `leaders` — `top_*.players`; не передавать для карточки матчей. Пустой массив → «нет матчей» (`emptyText`).
- `loading: true` — скелетон той же высоты.

**Правила**
- Шесть карточек в двух блоках, по три в ряд (`.qs-cards`); уже ~15rem карточки встают в колонку.
- Число всегда `ink` (в пустом дне — `ink-muted`), никогда `accent`: акцент у ников лидеров.
- В пустой день карточки показывают «0», а под рядом ставится `EmptyState({ kind: 'day' })`.
- Ничья не ломает карточку: LeaderList показывает троих и сворачивает остальных в «+N».
