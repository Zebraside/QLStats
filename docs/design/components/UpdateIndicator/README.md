Тихая подпись в шапке о свежести статистики: «обновлено N с назад».

**Что передать.** `QLStats.UpdateIndicator({ status, updatedAt, retryAt })`.
- `status: 'ok'` — `updatedAt` — время последнего успешного ответа `/api/summary` или `/api/players` (ms клиента). Текст тикает раз в секунду через `QLStats.startTicker`: «обновлено 12 с назад», потом «… мин назад».
- `status: 'loading'` — «загрузка…» при первом запросе.
- `status: 'error'` — «не удалось обновить, повтор через 30 с» с обратным отсчётом до `retryAt`, иконка `warn`, текст `ink`. Данные на странице при этом остаются прежними.

**Правила**
- Всегда `ink-muted` и `body-sm`, без accent: это служебная подпись, а не сигнал. Ошибку отличают иконка, яркость `ink` и пунктирное подчёркивание.
- Касается только статистики (раз в 30 с). Связь с игровым сервером показывает LiveMatch, их не смешивать.
- Тикающий текст не помечен как live-регион. Об ошибке программам экранного доступа сообщает скрытая фраза.
