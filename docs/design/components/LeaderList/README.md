Список лидеров внутри StatCard: все игроки с максимальным значением, ники цвета `accent`.

**Что передать.** `QLStats.LeaderList(players, { max: 3 })`, где `players` — `top_*.players` из `/api/summary`.

**Правила**
- При ничьей показываются все лидеры. Если их больше `max` (3), видны первые три, остальные сворачиваются в кнопку «+N». Кнопка раскрывает список (`aria-expanded`), в `title` — имена скрытых.
- Каждый ник в одну строку: многоточие, полный ник в `title`. Карточка не растягивается.
- У списка есть `aria-label`: «Лидер» или «Лидеры, поровну: N».
- Порядок — как пришёл из API.
